## About me

I'm a student and developer from Tunisia interested in applied AI, health informatics, agriculture, climate risk, and thoughtful user experience. I like building small systems with clear limits and readable behavior.

## Featured projects

| Project | Focus | Repository |
|---|---|---|
| [CropGuide AI](https://github.com/amkkoussay/cropguide-ai) | Agricultural decision support with explicit uncertainty, data audits, and tests | JavaScript, React, Node.js |
| [Rain2Risk](https://github.com/amkkoussay/rain2risk) | Transparent relative flood-risk screening with documented data limits and tests | Python, Flask |

The projects above are exploratory software. CropGuide AI is not a substitute for agricultural expertise; Rain2Risk is a screening score, not an official warning or forecast.
